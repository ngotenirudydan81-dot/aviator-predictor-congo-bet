   - Cliquez "+ New +"
   - Choisissez "Web Service"
   - Sélectionnez votre repo
   - `aviator-predictor-congo-bet`

4. **Configurer le service**
   ```
   Name: aviator-predictor
   Environment: Python 3
   Build Command: pip install -r requirements.txt
   Start Command: gunicorn --bind 0.0.0.0:$PORT wsgi:app
   Instance Type: Free (gratuit)
   ```

5. **Créer et déployer**
   - Cliquez "Create Web Service"
   - Attendez le déploiement (2-3 min)
   - Vous recevrez une URL unique

6. **Accédez sur téléphone**

## 📞 TROUBLESHOOTING

### **"Application lente"**
- Render peut être lent au démarrage
- Attendez 30 sec après visite
- Problème résolu? Contactez support

### **"Erreur 502 Bad Gateway"**
- Application crash
- Vérifier logs sur Render
- Redéployer

### **"URL ne fonctionne pas"**
- Vérifier déploiement terminé
- Attendre 2-3 minutes
- Actualiser page

### **"Dashboard blanc"**
- Cache navigateur
- Faire Ctrl+Shift+R (Cmd+Shift+R Mac)
- Effacer cache sur mobile
