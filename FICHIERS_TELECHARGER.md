## 🚀 UTILISATION

### Après téléchargement:

```bash
# 1. Installer les dépendances
pip install -r requirements.txt

# 2. Créer l'environnement
python -m venv venv
source venv/bin/activate  # ou venv\Scripts\activate sur Windows

# 3. Démarrer
python app.py
# ou
./start.sh
```
